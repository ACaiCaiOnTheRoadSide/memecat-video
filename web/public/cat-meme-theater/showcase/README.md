# 落地页案例区

把你想展示的案例视频直接放进这个目录，落地页（`/`）的「案例剧场」会自动读取，无需改代码。

## 放什么

- 支持格式：`.mp4` `.webm` `.mov` `.m4v`
- 建议 2 个主推案例，文件名加数字前缀控制顺序，例如：

```text
showcase/
├── 01-菜鸟猫的第一天.mp4
├── 02-会议室惊魂.mp4
└── cases.json          # 可选
```

文件名去掉前缀后会作为默认标题，所以 `01-菜鸟猫的第一天.mp4` 显示为「菜鸟猫的第一天」。

## 自定义标题和描述（可选）

新建 `cases.json`，按文件名覆盖标题：

```json
[
  { "file": "01-菜鸟猫的第一天.mp4", "title": "菜鸟猫的第一天", "note": "6 个分镜，30 秒出片" },
  { "file": "02-会议室惊魂.mp4", "title": "会议室惊魂", "note": "全程只写了一句创意" }
]
```

## 自动收集的成片

除人工案例外，`cat-meme-theater/exports/` 下用户导出的 mp4 会被自动收集，按时间倒序最多展示 12 条。
